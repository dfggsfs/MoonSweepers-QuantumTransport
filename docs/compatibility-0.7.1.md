# 0.7.1：Steam Build 26264480 兼容性修订

另一台电脑的诊断报告显示Steam Build 26264480；开发电脑更新后，两项SHA-256与该报告完全一致。0.7.0仅适配Build 26203101，本版改为适配26264480；不同时承诺旧构建兼容。

从更新后的游戏文件，在独立目录重新运行原版Lustral 0.1.0生成器，生成并预编译完整接口。Unity仍为6000.6.0f1，元数据头为v108，Il2CppInterop为2.0.0-beta.8。生成器使用已校验的本机Unity补全库缓存；这不代表重新验证了外网下载，也没有运行MoonSweepers.exe。

对照旧接口快照后，确认原版存在方法增删；针对新生成接口编译插件，并通过库存、生产、归属、原版月石交付、网络钩子、菜单恢复、UGUI/TMP及配置迁移的离线检查。接口存在和编译成功不能证明原版方法内部行为完全不变，新构建中的加工链、采集来源、UI和实际联机仍需玩家验证。

本版将游戏指纹统一到distribution/game-compatibility.json。Core程序集内嵌该配置，完整包清单、运行前检查和只读诊断工具使用同一份数据。加载器及Mod运行时仍拒绝未知构建；旧构建的接口缓存也不作为新构建的可复用接口。

本次离线验证：编译零警告、零错误；核心237,867项断言；接口与配置181项检查；安装器82项检查（主回归49、权限9、CMD入口9、长路径15）。真实生成在复制的游戏文件中完成，断网/生成失败、部分复制失败和不兼容加载器等故障通过隔离场景验证；真实双人联机与游戏内生产不包含在这些结果中。

安装器现在区分文件缺失和指纹不匹配。后者显示相对文件名、支持构建、Steam记录的构建、期望/实际SHA-256；Steam记录仅作辅助，不能替代文件校验。包内新增“诊断游戏版本.cmd”，在桌面生成JSON，只读取指纹和构建记录，不读取存档、不启动游戏、不上传。

运输分配、车库库存、月石入站、联机交接协议与0.7.0相同。面板版本标记更新为0.7.1；原有动画、总开关、关闭恢复和配置保留逻辑继续使用。

升级方法：保存并退出游戏，将整个QuantumTransport-0.7.1-OneClick文件夹解压到游戏目录，双击“一键安装.cmd”。旧版安装包文件夹无需保留在原位；无需手动删除Lustral或Mods。新版安装器备份旧插件、配置和当前用户存档，保留配置及其他Mod，并在需要时重新生成本机构建接口。完整包不含游戏DLL、个人存档或开发机接口。
