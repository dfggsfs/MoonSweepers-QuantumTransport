# 量子传送 0.7.1 完整一键安装

本包内置 **Lustral 0.1.0 加载器、.NET 运行时和量子传送 Mod**。玩家无需单独下载加载器、安装 .NET SDK 或填写游戏路径。

**0.7.1 更新**：适配 Steam Build 26264480，重新生成并检查接口。运行时、安装器与诊断工具共用指纹配置；安装失败分别报告文件缺失和哈希不匹配，后者会显示支持构建、Steam记录构建及实际/期望SHA256。本包增加“诊断游戏版本.cmd”，结果输出到桌面JSON，不修改游戏或读取存档。

沿用0.7.0的按钮视觉状态、悬停/按压/焦点反馈、开合及切页动画、分页边界禁用、PgUp/PgDn与减少动态效果配置。完整实现说明见 README.md。

保留0.6.1的退出修复：关闭面板使用 Resume 返回游戏，不调用保存退出；底层确认框按键隔离。左侧运输总开关和 Ctrl+F8 同步，切换后保持面板打开。

Ctrl+F7 打开/关闭，Esc 或右上角“关闭面板”也可返回。三页显示运输总览、机器状态、分配规则；已有车库月尘量子供料保留。面板沿用原版菜单屏蔽操作，单人暂停时生产进度可能保持不变。

保留安装器修订 2 的长路径备份修复：存档复制与 SHA256 校验均使用长路径接口，无需修改注册表或系统设置。

如果旧安装器在“[2/5] 备份”阶段出现“未能找到路径的一部分”，请保留旧备份和日志，再把本包完整解压到游戏目录运行“一键安装.cmd”。旧包在此阶段失败尚未开始替换加载器和 Mod，不需要卸载游戏或删除存档。看到窗口首行“量子传送 0.7.1”即可确认用的是新版。

## 只需这样使用

1. 先在游戏内保存，然后关闭游戏。
2. 解压 ZIP，把里面的整个 **QuantumTransport-0.7.1-OneClick** 文件夹放到游戏目录，和 **MoonSweepers.exe** 并列。
3. 打开这个文件夹，双击 **一键安装.cmd**。Windows 如果要求管理员写入权限，允许后会自动继续。
4. 等到显示“安装成功”，正常从 Steam 启动游戏。

放置示例（游戏可在任何盘符，不限定 Steam 默认位置）：

```text
Moon Sweepers/
├─ MoonSweepers.exe
├─ GameAssembly.dll
├─ MoonSweepers_Data/
└─ QuantumTransport-0.7.1-OneClick/
   ├─ 一键安装.cmd          ← 双击这个
   ├─ 安装前检查.cmd
   ├─ scripts/
   ├─ payload/
   └─ …
```

不要直接在 ZIP 内运行，不要只复制脚本，也不要把文件夹放进 Mods 或 MoonSweepers_Data。若提示“位置不对”，通常是多套了一层目录：让一键安装脚本所在文件夹的上一级直接看到 MoonSweepers.exe。

## 首次安装与检查

本包固定适配 **Windows x64、Moon Sweepers / Steam Build 26264480**。检查的是核心文件指纹，游戏更新或另一构建版本不匹配时会停止。

首次会使用加载器自带工具，从你本机游戏文件生成接口，不启动游戏。**首次接口补全可能需要联网访问 GitHub**，已有完整、匹配缓存时可以复用。过程可能持续数分钟，请等待；详细进度在 logs 内的 generator 日志。

如果接口补全没有成功，安装程序会报错并恢复原有安装，不把“缺少所需接口”当作安装成功。遇到网络故障，联网后重新运行即可。安装前检查.cmd 只检查包、版本和冲突，不生成接口，不修改游戏文件。

## 已有 Mod 或旧版本

- 已安装0.5、0.6或0.7版本时，关闭游戏后直接运行新版一键安装即可；无需先删除Lustral或Mods。旧安装包文件夹只存放安装材料，可在保留日志后移走；游戏目录QuantumTransportBackups建议保留。
- 原配置原样保留，其他 Mod、加载器数据及个人存档不覆盖。若原配置关闭了量子传送，安装后仍保持关闭，可在游戏内按 Ctrl+F8 开启。
- 相同版本 Lustral 可以修复/重装，重复安装会重新备份，Mod 数据目录不删除。
- 检测到其他加载器、其他版本代理 winhttp.dll 或无法确认版本的加载器时会停止，保留原文件；不自动把几套加载器叠在一起。
- 不自动更新加载器版本；新建的 loader.toml 默认关闭加载器自动更新。
- 管理员授权安装时仍按原玩家身份备份存档，并准备该玩家写入加载器配置、日志和运行数据的权限，不为所有人开放整个游戏目录。

## 备份与日志

安装前备份旧加载器、量子传送插件及配置；当前用户 MoonSessions 存档另作一份备份并核验。备份放在 **游戏目录/QuantumTransportBackups/时间编号/**，与本安装包文件夹分开保存。安装日志与生成器日志在 **本安装包/logs/时间/**。

可捕获的安装失败会自动恢复本次已替换的文件。断电、强制结束安装器或磁盘故障可能中断恢复；这时保留备份和 install-journal.json，不要直接删除它们。安装程序不会自动回写旧存档。

安装完成后可移走安装包文件夹；已安装文件在游戏目录的 winhttp.dll、Lustral、Mods/local.quantumtransport 中。请保留备份。首次安装至少预留 2GB 空间以容纳生成、临时文件和备份，存档/旧安装较大时需要更多。
